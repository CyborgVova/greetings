### Использование докера

``` bash
    // сборка образа, после выполнения локально будет образ hello-server:latest
    docker build -t hello-server .

    // создаем и запускаем контейнер
    docker run --rm -d --name hello -p 8080:8080 hello-server

    // флаги:
    // --rm     - удаляет контейнер после его остановки
    // -d       - запускаем контейнер в тихом режиме как демон
    // --name   - именуем контейнер для возможности управления используя имя
    // -p       - проброс порта между хостом и контейнером host_port:container_port
```
